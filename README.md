# Noviq

Noviq ist ein smarter Produktfinder. Die Website hilft Nutzern, Wünsche, Budget und Anforderungen zu strukturieren und daraus Produktsuchen zu erstellen.

## Struktur
- `public/index.html` – komplette Website
- `wrangler.jsonc` – Cloudflare Workers Static Assets

## Aktueller Stand
Die Website erzeugt direkte Amazon.de-Suchlinks. Echte einzelne Produktkarten, Preise und Produktbilder werden später über eine sichere API-/Server-Integration ergänzt.
